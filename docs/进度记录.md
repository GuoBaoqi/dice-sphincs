## 小笔记
- cmake 不指定-G 参数会使用*平台默认的构建工具*，linux下是make，windows下是MSbuild。
- cmake 使用的构建工具中Ninja的优势是极简、依赖关系精确、大项目里重新配置和增量构建明显更快，除非像是嵌入式工具链这种只支持make的平台，使用Ninja会有很大提升
- compile_commands.json 可以用来帮助clangd等工具正常识别文件结构和编译路径 使用```-DCMAKE_EXPORT_COMPILE_COMMANDS=ON```的cmake开关生成
- 完整构建指令 ```cmake -S . -B build -G Ninja -DCMAKE_EXPORT_COMPILE_COMMANDS=ON``` ```cmake --build build```
